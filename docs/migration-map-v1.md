# Migration Map v1

Source schema: `/Users/minhlt/Downloads/Projects/TrueCare/truecare/generated/migrations/V001__init.sql`

This is the first table-level migration contract for the Python/FastAPI port. It is intentionally conservative: tables required by product parity are kept, infra-specific tables are replaced with the new Postgres event ledger, and analytics-only tables are archived until a current route needs them.

## Verification Defaults

- Critical kept tables must pass row-count checks, FK integrity checks, and tenant-scoped sample reads.
- RLS mapping starts with app-level filters in Phase A, then DB RLS before production cutover.
- Rollback for production remains restore-from-backup plus forward fix; local Alembic downgrades are allowed only when safe.
